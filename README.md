# Shopping Cart Agent

Aplicación de carrito de compras administrada completamente por un agente de IA.

El agente interpreta las solicitudes del usuario y ejecuta las acciones correspondientes sobre el carrito, como:

* Buscar productos.
* Agregar productos al carrito.
* Actualizar cantidades.
* Eliminar productos del carrito.
* Consultar el contenido del carrito.
* Finalizar la compra (checkout).

El objetivo del proyecto es demostrar cómo un agente puede gestionar todo el flujo de compra mediante lenguaje natural, actuando como la interfaz principal entre el usuario y la aplicación.
